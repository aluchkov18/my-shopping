# My Shopping — собирач на цени

Фаза 0 од проектот: секој ден ги чита јавните ценовници на маркетите во Велес и ја чува историјата.

## Што чита

| Синџир | Извор | Продавници во Велес |
|---|---|---|
| Жито маркети | zito.proverkanaceni.mk | сите со „Велес" во името |
| Стокомак | stokomak.proverkanaceni.mk | сите со „Велес" во името |
| КАМ | kam.mk (PDF по продавница) | според градот во списокот |
| Рамстор | ramstore.com.mk/marketi | Рамстор Велес |

Градот и синџирите се во `stores.json`.

## Каде завршуваат податоците

- `data/current/<синџир>/<продавница>.csv` — денешните цени, се презапишуваат секој ден
- `data/changes/<датум>.csv` — што е ново, што исчезнало, каде се сменила цена или акција
- `data/runs/<датум>.json` — извештај: што е прочитано, колку редови, што паднало

Историјата на секоја цена е во историјата на репото.

## Кога се врти

Секој ден во 10:40 (зиме) преку GitHub Actions, работен тек „Дневни цени". Може и рачно: Actions → Дневни цени → Run workflow.

## Правила на читање

- Се претставува со јасен User-Agent и почитува `robots.txt`.
- Чека 1,2 секунди меѓу барања кон ист сајт.
- Пад на една продавница не ги запира другите; сè се запишува во извештајот.

## Локално

```
pip install -r requirements.txt pytest
python -m pytest -q
python -m collector.run kam
```
