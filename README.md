# My Shopping — собирач на цени

Фаза 0 од проектот: секој ден ги чита јавните ценовници на маркетите во Велес и ја чува историјата.

## Што чита

| Синџир | Извор | Продавници во Велес |
|---|---|---|
| Жито маркети | zito.proverkanaceni.mk | сите со „Велес" во името |
| Стокомак | stokomak.proverkanaceni.mk | сите со „Велес" во името |
| КАМ | kam.mk (PDF по продавница) | според градот во списокот |
| Рамстор | ramstore.com.mk/marketi | Рамстор Велес |

Градот и синџирите се во `stores.json`.

## Каде завршуваат податоците

- `data/current/<синџир>/<продавница>.csv` — денешните цени, се презапишуваат секој ден
- `data/changes/<датум>.csv` — што е ново, што исчезнало, каде се сменила цена или акција
- `data/runs/<датум>.json` — извештај: што е прочитано, колку редови, што паднало

Историјата на секоја цена е во историјата на репото.

## Кога се врти

Секој ден во 10:40 (зиме) преку GitHub Actions, работен тек „Дневни цени". Може и рачно: Actions → Дневни цени → Run workflow.

## Правила на читање

- Се претставува со јасен User-Agent и почитува `robots.txt`.
- Чека 1,2 секунди меѓу барања кон ист сајт.
- Пад на една продавница не ги запира другите; сè се запишува во извештајот.

## Каталог (фаза 1, прва рака)

`catalog/needs.py` е списокот на потреби: што купува едно домаќинство, без оглед на бренд (трајно млеко, бел леб, сончогледово масло...). Секоја потреба има единица за споредба и правила што кажуваат кои редови од ценовниците спаѓаат во неа.

```
python -m catalog.match            # преглед + catalog/needs.csv + catalog/matches.csv
python -m catalog.match -v         # и најевтиниот производ по синџир
python -m catalog.match jajca med  # сите производи за наведените потреби
```

- `catalog/needs.csv` — потреба, единица, број производи и најниска цена по единица кај секој синџир
- `catalog/matches.csv` — секој споен производ, со цена по единица и доверба

Цената по единица доаѓа од два независни извора: количината прочитана од називот и единечната цена што ја објавува синџирот. Доверба 3 значи дека се согласуваат, 2 дека има само назив, 1 дека има само објавена цена, 0 дека не се согласуваат (тогаш редот нема цена и чека проверка), а -1 дека цената отскокнува од потврдените.

Правилата се груби и служат за избор на кандидати. Точното спојување по бренд и количина доаѓа во следниот чекор.

### Ист производ кај повеќе синџири

```
python -m catalog.same             # извештај + catalog/same.csv + catalog/same_review.csv
python -m catalog.same 40          # и 40 случајни сигурни парови за проверка со око
python -m catalog.same 40 веројатни
```

Ценовниците немаат баркод, па ист производ се препознава по називот: иста потреба, иста количина, ист бренд и варијанта. Цената не учествува во одлуката.

- `catalog/same.csv` — групи на ист производ со цената кај секој синџир (само сигурните)
- `catalog/same_review.csv` — веројатни парови, каде едниот назив има збор-два повеќе; чекаат преглед
- `catalog/review.csv` — пресудите од прегледот (да или не); важат и за следните денови
- `python -m catalog.export <папка>` — трите табели за листот за читање
